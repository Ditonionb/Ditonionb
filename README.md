# DiLa TV

DiLa TV is a cinematic streaming experience inspired by premium platforms and built with Next.js 14, React, and Tailwind CSS. The app ships with a curated catalog of fictional films, series, and documentaries, full-screen hero moments, watchlist management, and rich detail pages featuring trailers, episodes, and recommendations.

## Getting started

```bash
npm install
npm run dev
```

The development server will start on [http://localhost:3000](http://localhost:3000). Log in is not required—browse categories, search for titles, and curate your watchlist right away.

## Key features

- **Responsive hero landing page** highlighting the flagship release with watchlist controls.
- **Dynamic categories** with smooth horizontal scrolling for trending, exclusive, documentary, and Top 10 collections.
- **Search experience** that surfaces results by title, genre, or cast with helpful fallback suggestions.
- **Persistent watchlist** powered by local storage so you can save titles across sessions.
- **Show detail hub** with adaptive video player, episode browser for series, and smart recommendations.

## Tech stack

- [Next.js](https://nextjs.org/) App Router
- [React](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)

## Available scripts

- `npm run dev` – start the development server.
- `npm run build` – create an optimized production build.
- `npm run start` – serve the production build.
- `npm run lint` – run ESLint using Next.js defaults.
